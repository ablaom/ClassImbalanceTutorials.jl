# Notice to users

After cloning the ClassImbalanceTutorials.jl repository, activate the Julia package
environment represented by Project.toml in the current directory, using Julia 1.12 or
higher, and execute the Julia script notebook.jl, which includes a narrative as code
comments.

# Notice to maintainers

The ground truth is notebook.jl, which must be Literate.jl-compiant. GitHub CI automates
the generation and commitment of notebook.md, which is integrated into the repo GH pages
generated by Documenter.jl in CI.

The file notebook.pdf must be generated by hand, and committed in a new PR, after merging
any changes to the .jl and .md files, using the utility `md2pdf` in this folder. It's
purpose is to generate a file for journal review purposes and **may not be kept synchronized
with the source.**
